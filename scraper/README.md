# Target classification

**Target Site:** Books to Scrape (https://books.toscrape.com)

**Why:** The site explicitly states it is a sandbox designed for people to practice web scraping.

**How much:** The scope is limited to the first 3 catalogue pages only (and their 60 corresponding book pages).

**What data:** We collect book details (e.g., title, price, availability).
**Appropriateness:** Since the site is a dedicated scraping sandbox and we are restricting our scope to a small subset of pages, it is appropriate and safe to scrape here.

**Robots Result:** Checked `https://books.toscrape.com/robots.txt` - no robots file found.

I will not reuse this code on another site without checking its rules and terms first.
